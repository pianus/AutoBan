# data/

Your working data lives here and is **excluded from Git** (see `.gitignore`).

| Item | Created by | Purpose |
|---|---|---|
| `autoban-data.json` | AutoBan → *Create new file…* | All weeks, issues, settings. The source of truth. |
| `attachments/` | AutoBan attachment panel → *Choose folder…* | Copies of pictures, videos and files you attach. |
| `backups/` | You (optional) | Files from *Export copy*. |

If `Documents` is synced by OneDrive (common on company laptops), this folder syncs automatically and you can open the same data file on another machine.
